- rolled from NOW.md: 2026-09-25 **The §5 floor rule got a literal test, and applying it as written would flag most of the index at once** (`38d6d49`, `scripts/quality-metrics.mjs`). Why: the floor rule names a specific number, whether removing a source changes the composite by less than the published error band, but §2 (redundancy) and §3 (the band) never computed that number; redundancy is a proxy for the floor rule, not the test itself. The script now does the leave-one-out test directly: for every day a source contributed, it recomputes the composite with that source's rows pulled from its pillar and averages the swing. First read, 117 days, 16 composite-eligible sources: every one swings less than the 6.79-point band, from 0.30 (newsapi) to 5.40 (serpapi_linkedin). Recorded as a finding, not a retirement case: most pillars carry several sources, so one source's share of a pillar mean is diluted while the band is resampled across all three pillars at once, meaning a composite-wide band would structurally under-run for any single source in a multi-source pillar, four weeks running, regardless of redundancy. Flagged for Krish as an open design decision, composite-wide band versus one scoped to each pillar, and not acted on; no source is proposed for retirement from this first read either way.
- rolled from NOW.md: 2026-09-24 **§1 of the data-quality strategy executed for the first time, and the answer was "too early to tell"** (`2b0450d`, `scripts/validate-anchor.mjs`, `npm run validate`). Why: the programme adopted on 2026-09-21 had never been run, so the FWI had still never been checked against an external measure of what it claims to track. The script correlates the FWI against the three context inputs already excluded from the composite (`bls`, `fred`, `census_acs`), collapsed to one row per official release rather than one per day, because the collector snaps the latest published value daily and a naive daily join would inflate n by 20-30x, the exact pseudo-replication §1 warns about. Nothing is published from this; the finding is that the pipeline is too young to validate, stated precisely rather than approximately.
